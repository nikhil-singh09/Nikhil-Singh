# Portfolio Project Showcase

Executable local demonstrations corresponding to the case studies on the [Data & AI portfolio](https://nikhil-singh09-portfolio.netlify.app/).

| Portfolio case study | Local demo folder | Scope |
| --- | --- | --- |
| Vendor Contract Intelligence | [ai-contract-review-assistant](ai-contract-review-assistant/) | Evidence-linked rules on fictional text agreements |
| Debtor Collection Intelligence Copilot | [debtor-collection-copilot](debtor-collection-copilot/) | Validation and review-only worklist |
| Partner Communication Automation | [partner-communication-automation](partner-communication-automation/) | Grouped draft generation; never sends |
| Executive & Partner Performance BI | [executive-partner-performance-bi](executive-partner-performance-bi/) | Synthetic monthly KPI aggregation |
| Cloud Data Engineering & ETL Modernisation | [cloud-data-engineering-etl-modernisation](cloud-data-engineering-etl-modernisation/) | Local batch curation, rejects and summaries |
| Invoice Intelligence & RAG Pipeline | [invoice-intelligence-rag-pipeline](invoice-intelligence-rag-pipeline/) | Offline lexical retrieval with evidence |
| ETL Optimisation & Data Quality | [etl-optimisation-data-quality](etl-optimisation-data-quality/) | Validation, duplicate checks and rejects |
| QlikView & QMC BI Operations | [qlikview-qmc-bi-operations](qlikview-qmc-bi-operations/) | Synthetic reload-health metrics |
| Applied ML, Anomaly Detection & Forecasting | [applied-ml-anomaly-forecasting](applied-ml-anomaly-forecasting/) | Explainable z-score and linear trend baseline |
| Python & Excel Process Automation | [python-excel-automation](python-excel-automation/) | Multi-sheet consolidation and summary workbook |
| GenAI Chat with SQL Database | [genai-chat-with-sql-database](genai-chat-with-sql-database/) | Fixed read-only SQLite query router |
| NLP Chatbot & Recommendation Support | [nlp-chatbot-recommendation-support](nlp-chatbot-recommendation-support/) | Offline lexical FAQ/product matching |

The contract, debtor, ETL and analytics examples are independent recreations. All included data is synthetic. No client/employer data, confidential documents, credentials, automated email delivery or production service integrations are included. Each folder contains its own README, source, sample data, dependency file and workflow diagram.
